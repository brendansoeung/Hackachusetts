# MakeWeight: tech conventions

## Stack
- Plain HTML, CSS and vanilla JavaScript ES modules. No framework, no build step, no runtime dependencies.
- One Vercel serverless function: `api/coach.js`. Tries the Gemini Interactions API (`POST /v1beta/interactions`) first, then falls back to `models/{model}:generateContent` and a second model (`gemini-2.5-flash`). Stops immediately on 401/403 (bad key) and 429 (quota). Logs Google's status codes (never the key or prompt) to Vercel's function logs.
- PWA: `manifest.webmanifest` + `sw.js` (network-first, never caches `/api/`).
- Tests: Node's built-in runner (`node --test`). `jsdom` (pinned, dev only) for the UI smoke test.

## Layout
- `js/limits.js`: every safety threshold (single source of truth).
- `js/rules.js`: cut type, safety budget, goal check, day-by-day plan, red-flag adjustments. Pure functions.
- `js/alerts.js`: alerts from entries + plan. Pure functions.
- `js/recovery.js`: post-weigh-in plans (under 1 h, 1 to 6 h, 12+ h) and between-match fueling. Pure functions.
- `js/storage.js`: localStorage, validation, backup export/import, WHOOP-format conversion, demo loader.
- `js/coach-shared.js`: coach context schema, validation, safety system prompt (shared by browser and server).
- `js/coach.js`: browser coach client, briefing cache, rules-based fallback.
- `js/app.js`: UI only (routing, rendering, events). No safety math here.
- `data/sample-athlete.json`: demo athlete in WHOOP API format (generated by `scripts/build-sample.mjs`).
- `data/learn.json`: Safety tab cards.

## Conventions
- Keep logic in pure, tested modules; `app.js` only displays results.
- Dates are `'YYYY-MM-DD'` strings (see `js/dates.js`), never Date objects in state.
- Weights in lb, fluids in oz with mL secondary, nutrition in g/kg internally.
- Escape all text inserted into HTML (`esc()` in app.js). AI text is escaped, then only `**bold**` is allowed.
- No inline `style=""` attributes or inline scripts (the CSP in `vercel.json` blocks scripts that aren't from the site itself).
- Accessibility: every input has a label, 48px tap targets, `aria-live` for alerts/chat, status shown with text not just color.

## Security
- `GEMINI_API_KEY` lives only in Vercel env vars and a local `.env` (git-ignored). Never commit or log it.
- `/api/coach` is public with no login: keep the per-IP rate limit, strict validation (numbers-only context, rejects name-like keys, size caps) and capped output tokens.
- The model name comes from `GEMINI_MODEL` (default `gemini-flash-latest`).

## Commands
- `npm test`: run all tests (must pass before every commit).
- `npm run dev`: local server with the API at http://localhost:5173 (reads `.env`).
- `npm run build:sample` / `npm run build:icons`: regenerate demo data / icons.
